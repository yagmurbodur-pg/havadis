# Ajanlar için tarayıcı: ego-lite, oturumlarını Codex ve Claude Code'a açıyor

ego-lite, yapay zekâ ajanlarının web otomasyonu için tasarlanmış hızlı bir tarayıcı. Oturum açtığın tarayıcı durumunu, seni rahatsız etmeden Codex veya Claude Code gibi ajanlarla paylaşıyor. **Neden önemli?** Ajanların en büyük engellerinden biri girişli siteler; ego-lite kendi tarayıcı oturumunu ajana açmayı kolaylaştırıyor.
